ECO SMART

The IoT-based Smart Garbage Vehicle Allocation System uses ultrasonic and weight sensors with an ESP8266 to monitor bin status in real time. Data is sent to Firebase and displayed on a responsive web dashboard, which shows bin levels, sends alerts, and helps auto-allocate vehicles. The website allows easy tracking and management, making waste collection smarter, faster, and more efficient.
