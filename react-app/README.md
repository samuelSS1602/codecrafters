# Code Crafters — React conversion

This folder contains a minimal Vite + React port of the original `index.html`.

Quick start:

```bash
cd react-app
npm install
npm run dev
```

Notes:
- Assets (images) were referenced from the repository root. Copy them into `react-app/public` or adjust paths.
- The CSS was copied from the original page into `src/styles.css`. You can further split it into modules/components.
